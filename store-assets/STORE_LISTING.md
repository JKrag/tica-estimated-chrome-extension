# Chrome Web Store Listing Content

## Extension Name

TICA Estimated Standings Enhancer

## Summary (132 characters max)

Adds season navigation and top 25 highlighting to TICA unofficial estimated standings pages for cat show enthusiasts.

## Description (up to 16,000 characters)

Enhance your experience browsing the TICA (The International Cat Association) unofficial estimated standings website.

**Features:**

🔄 **Season Navigation**
Jump between show seasons (2012-13 through current) with a convenient dropdown at the top of each page. No more navigating back to the main page!

🏆 **Top 25 Highlighting**

- Gold highlighting for the top 25 cats in all-breed rankings
- Works on all ranking pages: Kittens, Championship Cats, Alters, and Household Pets

😺 **Championship Cat SH/LH Awards**
For championship cats, the extension tracks both Shorthair and Longhair categories:

- Teal highlighting for Shorthair runners-up making top 25 SH
- Pink highlighting for Longhair runners-up making top 25 LH
- Color-coded breed codes (blue for SH, pink for LH)
- Additional SH/LH ranking columns on the main championship page

📍 **Regional Page Support**
Full functionality on regional standings pages, correctly handling multiple sections (Kittens, Cats, Alters, HHP) within a single page.

**Privacy:**
This extension only runs on ticamembers.org/estimated_standings/* pages. It does not collect, store, or transmit any data. All functionality is performed locally in your browser.

**Open Source:**
Source code available at: <https://github.com/JKrag/tica-estimated-chrome-extension>

## Screenshot Capture Guide

To capture consistent screenshots at 1280x800:

1. Open Chrome DevTools (F12)
2. Click device toolbar (Ctrl+Shift+M)
3. Set dimensions to 1280x800
4. Navigate to the relevant page
5. Use "Capture screenshot" from DevTools menu (three dots → More tools)

Alternatively, resize browser window and use OS screenshot tools.
